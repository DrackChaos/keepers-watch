3D Assets — Final Folio

Photo: paws and prints / Unsplash

Each gallery below is ordered as a build breakdown — grouped by construction stage (block-out → UV → materials → final render) rather than a literal undo-history timeline, since process shots weren't always captured continuously. Each image is captioned with what that stage shows.

UV unwrapping

19 — Entrance ring UVThe ring is a torus, so a cube projection would stretch badly on the curve — used Smart UV Project instead, which auto-places seams and gave a clean, evenly-packed layout.
19b — Frame/slat UVBox-shaped parts (slats, floor, posts) unwrapped with Cube Projection, producing a proper unfolded net instead of relying on the default flat mapping Blender assigns to a new mesh.

Materials

20 — Driftwood material (procedural)Two layered Noise Textures — one through a ColorRamp for mottled base colour, one through Map Range into a Bump node for surface grain — instead of a single flat image texture, so the wood doesn't visibly tile across the repeated slats.
21 — Netting materialA simpler flat-colour Principled BSDF — the woven look here comes from real modelled geometry (the mesh grid itself), not a texture trick, so the material only needed to supply a plausible weathered-wire colour and roughness.

The wood material is procedural (noise-driven, not an image texture), which caused a real problem on first export: glTF/SketchFab can't interpret arbitrary shader node graphs, only flat values or actual image textures, so the exported model came out flat white where the wood should be. Fixed by baking the Driftwood material to a 2048×2048 image (Cycles, Bake Type: Diffuse → Color only) and rewiring that baked image into Base Color before re-exporting — along with turning on Apply Modifiers in the glTF export settings, which had been silently dropping modifier-driven geometry from the file.

Pier

Status: Fully modelled and textured. Scope grew significantly beyond the original "single repeating Pier Post" plan — after working from a boardwalk-pier reference image, this became a full branching walkway structure (multiple connecting sections, double-tier railings, clustered support posts with cross-bracing), a deliberate trade-off to get a stronger visual centrepiece for the scene. One consequence of that: the finished asset sits at roughly 162k triangles, well above the ~3,000 tri budget the Folio 1 plan set for this prop — a conscious choice to prioritise visual complexity here over the original Quest 3S budget, discussed further in the Reflection page.

UV unwrapping

14 — Deck plank UVFlat/boxy geometry → Cube Projection, same technique as the Lobster Trap's slats.
15 — Post UVCylindrical geometry → one vertical seam + Unwrap, giving an unrolled strip plus cap circles rather than a stretched cube projection.
16 — Railing UVFlat/boxy balusters and rails → Cube Projection again.

Materials

17 — WeatheredDeckA bigger node graph than the earlier Driftwood material — per-board and per-post random inputs feed separate noise layers, so individual planks and posts vary instead of repeating identically.
18 — WeatheredPaintSeparate material for the railings — a paler, chipped-paint look pulling from the same Fog Grey moodboard tone, rather than reusing the timber-brown palette everywhere.
19 — WeatheredPilingThird material for the support posts/braces, darker and rougher than the deck to read as waterline timber.

Same glTF export issue as the Lobster Trap, but across three separate procedural materials at once (WeatheredDeck, WeatheredPaint, WeatheredPiling) rather than one — the whole structure exported flat white on the first attempt. Fixed the same way: baked each material to its own image (Cycles, Diffuse/Color only) and rewired each into its Principled BSDF's Base Color before re-exporting.

Weathered Rowboat

Status: Fully modelled and textured. Beached/half-sunk storytelling prop — a mooring rope trails from the bow (physically connecting this asset to the Pier in the composed scene) and a small outboard motor was added as an extra detail beyond the original plan.

UV unwrapping

08 — Hull UVThe hull is a genuinely curved, organic shape — Smart UV Project auto-places seams and packs the layout without manual guesswork, same tool used on the Lobster Trap's entrance ring.
09 — Thwarts UVFlat bench seats → Cube Projection.
10 — Outboard UVBoxy motor housing → Cube Projection.

Materials

13 — WeatheredTimber_Rowboat (base)The starting wood material for the hull, following the same Driftwood-family node approach as the other assets.
14 — Waterline weathering extensionThe strongest technical work in the folio — a labelled node group using the hull's Z-position to mask a "tide line" band, blending in a cooler, damper colour and reducing roughness ("wet = less rough") toward the bottom of the hull. This is what actually sells "half-sunk," not just a dark colour choice.
15 — Wood grain layersThe underlying noise layers that give the grain its variation before the waterline extension blends over it.
